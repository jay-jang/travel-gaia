> The International Airlines Travel Agent Network — the North American subsidiary of IATA that accredits retail travel agencies and individual travel professionals, issues the industry-standard IATAN ID Card, and administers the shared IATA/ARC numeric location code used to identify US-based agencies in airline settlement.

IATAN (formerly the International Airlines Travel Agent Network) operates within the IATA framework to establish accreditation and professional standards for the North American retail travel distribution channel. An agency holding IATAN accreditation receives an IATA Numeric Code (7 or 8 digits) and is recognised by airlines and suppliers as an authorised issuing agent for tickets settled through the BSP or, for US domestic sales, through ARC. Critically, IATAN and ARC use the same numeric location coding scheme, so a dually accredited US agency carries a single shared IATAN/ARC number, avoiding duplication. Individual agents who meet qualification criteria (minimum sales volume, relevant coursework) may obtain an IATAN ID Card, a widely accepted industry credential granting access to agent fares (ID/AD fares) and familiarisation trips. Outside North America, agency accreditation is handled directly by IATA under the Travel Agent Commissioner programme; IATAN is specific to the US and Canadian market.

**한국어 / Korean** — **국제항공여행사네트워크(IATAN)** — IATA의 북미 자회사로, 소매 여행사 및 개인 여행 전문가를 인가하고, 업계 표준 IATAN ID 카드를 발급하며, 미국 소재 여행사를 항공사 정산에서 식별하는 데 사용되는 IATA/ARC 공동 숫자 로케이션 코드를 관리한다.

IATAN은 IATA 체계 내에서 북미 소매 여행 유통 채널의 인가 및 전문성 기준을 수립하고 운영한다. IATAN 인가를 받은 여행사는 IATA 숫자 코드(7~8자리)를 부여받고, BSP(미국 국내선의 경우 ARC)를 통해 정산이 이루어지는 항공권의 공인 발권 대리점으로 항공사 및 공급사에 인정된다. 중요한 점은 IATAN과 ARC가 동일한 숫자 위치 코드 체계를 사용한다는 것으로, 양쪽에 이중으로 인가된 미국 여행사는 중복 없이 하나의 공유 IATAN/ARC 번호를 갖는다.

# Distinctions
- **IATAN** vs [IATA Number](/common/codes/iata-number.md) — The IATA Number is the numeric code itself assigned to an accredited agency location; IATAN is the North American accreditation body and programme that administers that code for US and Canadian agencies.
- **IATAN** vs [ARC](/common/pay/arc.md) — ARC (Airlines Reporting Corporation) is the US ticket-settlement clearing house through which accredited US agencies report and settle; IATAN is the accreditation authority that issues the shared numeric code used by both ARC and IATAN-accredited agencies.
