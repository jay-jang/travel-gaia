> The International Ship and Port Facility Security Code (ISPS Code) is an IMO security standard adopted in December 2002 as an amendment to SOLAS Chapter XI-2, entering into force 1 July 2004. It establishes a standardized framework to detect and deter security threats to ships and port facilities, requiring passenger ships and cargo ships of 500 GT or more on international voyages to carry an International Ship Security Certificate (ISSC) and a continuously maintained Ship Security Plan (SSP). Port facilities serving such ships must be assessed and operate under an approved Port Facility Security Plan (PFSP).

The ISPS Code was adopted in response to the post-September 2001 security environment and entered into force 1 July 2004. It applies to all passenger ships, cargo ships of 500 GT and above on international voyages, and the port facilities that serve them. Part A contains mandatory requirements; Part B provides implementation guidance. Key elements: a Ship Security Officer (SSO) on board, a Company Security Officer (CSO) ashore, a Port Facility Security Officer (PFSO), three security levels (1 normal / 2 heightened / 3 exceptional) triggering escalating protective measures, a covert Ship Security Alert System (SSAS), and the International Ship Security Certificate (ISSC) verified by Port State Control. Non-compliance can result in ship detention.

**한국어 / Korean** — **국제선박 및 항만시설 보안규칙(ISPS Code)** — 국제선박 및 항만시설 보안규칙(ISPS Code)은 2002년 12월 SOLAS 제XI-2장 개정으로 채택된 IMO 보안 표준으로, 2004년 7월 1일 발효되었다. 선박과 항만시설에 대한 보안 위협을 탐지·억제하는 표준화된 체계를 수립하며, 국제 항해에 종사하는 여객선 및 총톤수 500 GT 이상의 화물선은 국제선박보안증서(ISSC)를 소지하고 선박보안계획서(SSP)를 유지해야 한다.

ISPS Code는 2001년 9월 11일 테러 이후 채택되어 2004년 7월 1일 발효되었다. 의무 요건(A편)과 이행 지침(B편)으로 구성되며, 선박보안책임자(SSO)·회사보안책임자(CSO)·항만시설보안책임자(PFSO), 보안 수준 1~3 체계, 선박보안경보시스템(SSAS), 국제선박보안증서(ISSC)가 핵심 요소다. 미준수 시 선박 억류 조치가 취해질 수 있다.

# Distinctions
- **ISPS Code** vs [ISM Code](/cruise/cruise/ism-code.md) — The ISM Code governs safety management — the organizational SMS framework to prevent maritime accidents and manage emergencies; the ISPS Code governs security management — preventing and responding to unlawful acts against ships and port facilities. Both are mandatory under SOLAS but are wholly separate codes addressing different domains.
- **ISPS Code** vs [SOLAS](/cruise/cruise/solas.md) — SOLAS is the parent convention containing many chapters governing diverse aspects of ship safety; the ISPS Code is a specific amendment to SOLAS Chapter XI-2 covering ship and port security alone.
