> Basic Economy is a deeply restricted, entry-level fare class offered by major full-service carriers to compete on price with low-cost carriers while retaining ancillary upsell opportunity. It typically excludes advance seat selection, ticket changes, refunds, standard carry-on allowances, and elite-qualifying miles, compelling passengers who need those features to purchase add-ons or upgrade to a higher fare class.

Basic Economy was introduced by major US carriers (United Airlines in 2012, Delta and American Airlines following by 2017) as a fare unbundling strategy: by removing inclusions that were standard in Economy, carriers could match low-cost carrier headline prices while recovering revenue through ancillary fees. Restrictions vary by carrier but commonly include no advance seat assignment (seat allocated at check-in or gate), no ticket changes or refunds, reduced or zero carry-on allowance, last boarding group, and reduced or zero elite-qualifying and award-mile accrual. Basic Economy fares are typically filed in the same booking class (RBD) as standard Economy but carry a distinct fare basis code and rule set that triggers the restrictions. ATPCO distributes these fare rules as standard fare records.

**한국어 / Korean** — **베이직 이코노미(Basic Economy)** — Basic Economy는 대형 네트워크 항공사들이 저비용 항공사와 가격 경쟁을 하면서도 부가 서비스 업셀(ancillary upsell) 기회를 확보하기 위해 제공하는 최고 제한 등급의 항공권이다. 일반적으로 사전 좌석 선택, 항공권 변경, 환불, 기내 수하물 반입, 실적 마일리지 적립이 제외되며, 이 혜택이 필요한 승객은 옵션을 추가 구매하거나 상위 운임으로 업그레이드해야 한다.

Basic Economy는 미국 대형 항공사(United Airlines 2012년, Delta·American Airlines 2017년 전후)가 운임 언번들링(fare unbundling) 전략으로 도입했다. 이코노미의 기본 포함 항목을 제거함으로써 저비용 항공사의 기본 가격에 맞추면서도 부가 서비스 수수료로 수익을 회수할 수 있게 됐다. 제한 사항은 항공사마다 다르지만 일반적으로 사전 좌석 배정 불가(체크인·게이트에서 배정), 변경·환불 불가, 기내 수하물 반입 축소 또는 불가, 마지막 탑승 그룹, 실적 마일리지·어워드 마일리지 적립 축소 또는 불가 등이 포함된다. Basic Economy 운임은 일반 이코노미와 동일한 예약 등급(RBD)에 등록되는 경우가 많지만, 제한을 발동하는 별도의 운임 기준 코드(fare basis code)와 규정 세트를 가진다. ATPCO는 이러한 운임 규정을 표준 운임 레코드로 배포한다.

**Aliases:** `Basic Fare`, `Light Fare`, `Entry-Level Economy`

# Distinctions
- **Basic Economy** vs [Low Cost Carrier](/air/air-shop/low-cost-carrier.md) — A low-cost carrier is an airline business model built on unbundled fares from the ground up, typically without interlining, lounges, or full-service hospitality; Basic Economy is a restricted fare class offered by full-service network carriers designed to match LCC headline prices while keeping the carrier's full network and services available at higher fare classes.
- **Basic Economy** vs [Ancillary Service](/air/air-ticket/ancillary-service.md) — An ancillary service is an optional product sold in addition to the base fare (seat selection, checked bag, meal); Basic Economy is a fare class defined precisely by the removal of items that would otherwise be included — those removed items are then resold as ancillaries.
- **Basic Economy** vs [Full-Service Carrier](/air/air-ops/full-service-carrier.md) — A full-service carrier bundles seat, carry-on, meals, and changes into standard Economy; Basic Economy is offered by full-service carriers precisely to strip those inclusions and create a headline price competitive with low-cost carriers.
