> BCBP (Bar Coded Boarding Pass) is the IATA standard, defined in Resolution 792 and maintained in the BCBP Implementation Guide, that specifies the data content and 2-D barcode symbologies — PDF417, Aztec, Data Matrix, and QR Code — to be encoded in machine-readable boarding passes issued at airport kiosks, airline counters, home printers, and mobile devices. It ensures that boarding passes generated by any carrier or airport system can be scanned by any compliant gate reader worldwide.

IATA Resolution 792, first adopted in 2001 and maintained in the BCBP Implementation Guide (7th edition, 2021), defines the mandatory and optional data elements encoded in every compliant boarding pass barcode. Mandatory fields include: passenger name, operating carrier PNR code, departure and arrival airport IATA codes, operating carrier designator and flight number, flight date, compartment code (booking class), seat number, check-in sequence number, and passenger status. The standard covers four symbologies: PDF417 (the legacy primary format), Aztec Code, Data Matrix, and QR Code — the latter three enabling compact encoding suited to mobile-screen display. BCBP underpins industry programs including IATA's Mobile Boarding Pass specification and the Common Use Self-Service (CUSS) kiosk standard. Airport common-use terminal equipment (CUTE) and departure control systems (DCS) consume the BCBP barcode to validate passenger identity and boarding entitlement at the gate.

**한국어 / Korean** — **바코드 탑승권(BCBP)** — BCBP(Bar Coded Boarding Pass)는 공항 키오스크·항공사 체크인 카운터·가정용 프린터·모바일 기기에서 발급되는 기계 판독 탑승권에 인코딩할 데이터 내용과 2차원 바코드 형식(PDF417, Aztec, Data Matrix, QR 코드)을 규정한 IATA 표준(Resolution 792 및 BCBP Implementation Guide)이다. 어떤 항공사·공항 시스템이 생성한 탑승권이든 전 세계 규격 게이트 스캐너에서 읽을 수 있도록 보장한다.

IATA Resolution 792(2001년 최초 채택, BCBP Implementation Guide 제7판 2021년 현재 유지)는 규격 탑승권 바코드에 인코딩되는 필수 및 선택 데이터 요소를 정의한다. 필수 필드: 승객명, 운영 항공사 PNR 코드, 출발·도착 공항 IATA 코드, 운영 항공사 코드 및 편명, 비행 날짜, 구획 코드(예약 등급), 좌석 번호, 체크인 일련 번호, 승객 상태. 표준은 PDF417(구형 기본), Aztec Code, Data Matrix, QR Code 네 가지 형식을 규정하며, 후자 세 형식은 모바일 화면 표시에 적합한 소형 인코딩을 가능하게 한다. BCBP는 IATA 모바일 탑승권 사양 및 공용 셀프서비스(CUSS) 키오스크 표준의 기반이 되며, 공항 공용 단말 장비(CUTE)와 출발 통제 시스템(DCS)은 게이트에서 승객 신원 및 탑승 자격 검증에 BCBP 바코드를 사용한다.

# Distinctions
- **BCBP** vs [Boarding Pass](/air/air-ops/boarding-pass.md) — A Boarding Pass is the travel document that authorises a passenger to board — it can be printed on paper or displayed digitally; BCBP is the IATA barcode encoding standard that governs exactly what data must be encoded in the 2-D barcode on that document so that any gate scanner worldwide can read it interoperably.
- **BCBP** vs [Digital Travel Credential](/common/customer/digital-travel-credential.md) — A Digital Travel Credential (DTC) is an ICAO standard for a chip-based, cryptographically verifiable digital equivalent of a passport; BCBP is an IATA standard for the data barcode on an airline boarding pass. DTC addresses identity verification at border control; BCBP addresses boarding eligibility encoding for airport gate scanning.
